# Notebook View — Implementation Plan (2026-07-07)

Transform the Quizify canvas into a notebook-style experience: no card boundaries, a ruled-page background, character-by-character typewriter animation for text reveal, and auto-synced TTS that reads each concept aloud as it's "written".

**Status**: Approved. Ready for implementation.

## Step 3 — TTS Manager (`src/lib/llm/ttsManager.ts`)

**New file**. A singleton class that replaces the ad-hoc `fetchTtsBlob` usage in `ConceptNode.tsx`. Provides a queue-based, controllable TTS system with per-character progress callbacks for sync with typing animation.

### Architecture

```
         pipeline.ts            ConceptNode.tsx (via hook)
              │                        │
              │ enqueue()              │ setCallbacks()
              ▼                        ▼
         ┌─────────────────────────────────────┐
         │            TtsManager               │
         │                                     │
         │  ┌────────┐  ┌────────┐  ┌───────┐ │
         │  │segment1│→ │segment2│→ │segment3│ │
         │  │node:a  │  │node:b  │  │node:c  │ │
         │  └────────┘  └────────┘  └───────┘ │
         │                                     │
         │  currentIdx: number                 │
         │  isPlaying: boolean                 │
         │  isPaused: boolean                  │
         └──────────────┬──────────────────────┘
                        │ play / pause / skip / stop
                        ▼
                Audio element (Mistral)
                or SpeechSynthesis (fallback)
                        │
                        │ onended / onboundary
                        ▼
                Callbacks: { onCharProgress, onSegmentStart,
                             onSegmentEnd, onQueueEnd }
```

### Full implementation of `ttsManager.ts`

```typescript
/**
 * TTS Manager — Queue-based text-to-speech with per-character
 * progress callbacks for typing animation synchronization.
 *
 * Modes:
 *   - Primary: Mistral Voxtral (fetch audio blob, play via <Audio>, calc sync from duration)
 *   - Fallback: Web Speech API (SpeechSynthesisUtterance with onboundary events)
 */

import { useSettingsStore } from '@/shared/stores/settingsStore';

export interface TtsSegment {
  nodeId: string;
  text: string;
}

export interface TtsCallbacks {
  /** Fired when a segment starts playing */
  onSegmentStart?: (nodeId: string) => void;
  /** Fired per character (approx) for typing animation sync */
  onCharProgress?: (nodeId: string, charIndex: number) => void;
  /** Fired when a segment finishes naturally */
  onSegmentEnd?: (nodeId: string) => void;
  /** Fired when the entire queue is exhausted */
  onQueueEnd?: () => void;
}

type TtsState = 'idle' | 'playing' | 'paused' | 'stopped';

class TtsManagerSingleton {
  private queue: TtsSegment[] = [];
  private currentIdx = -1;
  private state: TtsState = 'idle';

  private callbacks: TtsCallbacks = {};

  // Audio element for Mistral Voxtral playback
  private audioEl: HTMLAudioElement | null = null;
  private audioUrl: string | null = null;
  private rafId: number | null = null;
  private charCount = 0;
  private charsPerMs = 0;
  private startTime = 0;

  // SpeechSynthesis fallback
  private utterance: SpeechSynthesisUtterance | null = null;

  // ==================== Public API ====================

  enqueue(segment: TtsSegment): void {
    this.queue.push(segment);
  }

  enqueueMultiple(segments: TtsSegment[]): void {
    this.queue.push(...segments);
  }

  clearQueue(): void {
    this.queue = [];
  }

  start(): void {
    if (this.queue.length === 0 || this.state === 'playing') return;
    this.currentIdx = -1;
    this.playNext();
  }

  pause(): void {
    if (this.state !== 'playing') return;
    if (this.audioEl && !this.audioEl.paused) {
      this.audioEl.pause();
    } else if (window.speechSynthesis.speaking) {
      window.speechSynthesis.pause();
    }
    this.state = 'paused';
  }

  resume(): void {
    if (this.state !== 'paused') return;
    if (this.audioEl && this.audioEl.paused) {
      this.audioEl.play();
    } else if (window.speechSynthesis.paused) {
      window.speechSynthesis.resume();
    }
    this.state = 'playing';
  }

  stop(): void {
    this.cleanup();
    this.state = 'stopped';
    this.currentIdx = -1;
    this.queue = [];
    this.callbacks.onQueueEnd?.();
  }

  skip(): void {
    this.cleanup();
    this.callbacks.onSegmentEnd?.(this.queue[this.currentIdx]?.nodeId ?? '');
    this.playNext();
  }

  get isPlaying(): boolean {
    return this.state === 'playing';
  }

  get isPaused(): boolean {
    return this.state === 'paused';
  }

  get currentSegmentId(): string | null {
    return this.currentIdx >= 0 && this.currentIdx < this.queue.length
      ? this.queue[this.currentIdx].nodeId
      : null;
  }

  get queueLength(): number {
    return this.queue.length;
  }

  get currentQueueIndex(): number {
    return this.currentIdx;
  }

  setCallbacks(cb: Partial<TtsCallbacks>): void {
    this.callbacks = { ...this.callbacks, ...cb };
  }

  // ==================== Internal ====================

  private async playNext(): Promise<void> {
    this.currentIdx++;
    if (this.currentIdx >= this.queue.length) {
      this.state = 'idle';
      this.callbacks.onQueueEnd?.();
      return;
    }

    const segment = this.queue[this.currentIdx];
    this.state = 'playing';
    this.charCount = 0;
    this.charsPerMs = 0;
    this.callbacks.onSegmentStart?.(segment.nodeId);

    // Try Mistral Voxtral first
    const blob = await this.fetchTtsBlob(segment.text);
    if (blob) {
      await this.playAudioBlob(blob, segment);
    } else {
      this.playSpeechSynthesis(segment);
    }
  }

  private async fetchTtsBlob(text: string): Promise<Blob | null> {
    const { apiKey, provider } = useSettingsStore.getState();
    if (!apiKey || provider !== 'mistral') return null;

    try {
      const res = await fetch('https://api.mistral.ai/v1/audio/speech', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          Authorization: `Bearer ${apiKey}`,
        },
        body: JSON.stringify({
          model: 'voxtral-mini-tts-2603',
          input: text,
        }),
      });

      if (!res.ok) {
        console.warn('[ttsManager] Mistral TTS failed, falling back:', await res.text());
        return null;
      }

      return await res.blob();
    } catch (err) {
      console.error('[ttsManager] Mistral TTS network error:', err);
      return null;
    }
  }

  private async playAudioBlob(blob: Blob, segment: TtsSegment): Promise<void> {
    const url = URL.createObjectURL(blob);
    this.audioUrl = url;
    const audio = new Audio(url);
    this.audioEl = audio;

    // Wait for metadata to get duration
    await new Promise<void>((resolve) => {
      audio.addEventListener('loadedmetadata', () => resolve(), { once: true });
      audio.addEventListener('error', () => resolve(), { once: true });
      // Force load
      audio.load();
    });

    if (audio.duration && isFinite(audio.duration) && audio.duration > 0) {
      this.charsPerMs = segment.text.length / (audio.duration * 1000);
    }

    audio.onended = () => {
      this.callbacks.onCharProgress?.(segment.nodeId, segment.text.length);
      this.callbacks.onSegmentEnd?.(segment.nodeId);
      this.cleanup();
      this.playNext();
    };

    audio.onerror = () => {
      console.warn('[ttsManager] Audio playback error, skipping segment');
      this.cleanup();
      this.callbacks.onSegmentEnd?.(segment.nodeId);
      this.playNext();
    };

    this.startTime = performance.now();
    audio.play().catch(() => {
      // Autoplay may be blocked — fallback to SpeechSynthesis
      this.cleanupAudio();
      this.playSpeechSynthesis(segment);
      return;
    });

    // RAF loop for character progress
    const tick = () => {
      if (this.state !== 'playing') return;
      if (audio.paused || audio.ended) return;

      const elapsed = performance.now() - this.startTime;
      const estimatedChars = Math.min(
        Math.floor(elapsed * this.charsPerMs),
        segment.text.length,
      );
      if (estimatedChars !== this.charCount) {
        this.charCount = estimatedChars;
        this.callbacks.onCharProgress?.(segment.nodeId, estimatedChars);
      }
      this.rafId = requestAnimationFrame(tick);
    };
    this.rafId = requestAnimationFrame(tick);
  }

  private playSpeechSynthesis(segment: TtsSegment): void {
    const utterance = new SpeechSynthesisUtterance(segment.text);
    this.utterance = utterance;

    // Track character progress via word boundaries
    utterance.onboundary = (event) => {
      if (event.name === 'word') {
        // Estimate character index from the word's offset
        this.charCount = event.charIndex + event.charLength;
        this.callbacks.onCharProgress?.(segment.nodeId, this.charCount);
      }
    };

    utterance.onend = () => {
      this.callbacks.onCharProgress?.(segment.nodeId, segment.text.length);
      this.callbacks.onSegmentEnd?.(segment.nodeId);
      this.cleanupSpeech();
      this.playNext();
    };

    utterance.onerror = (event) => {
      console.warn('[ttsManager] SpeechSynthesis error:', event.error);
      this.cleanupSpeech();
      this.callbacks.onSegmentEnd?.(segment.nodeId);
      this.playNext();
    };

    window.speechSynthesis.speak(utterance);
  }

  private cleanupAudio(): void {
    if (this.rafId) {
      cancelAnimationFrame(this.rafId);
      this.rafId = null;
    }
    if (this.audioEl) {
      this.audioEl.pause();
      this.audioEl.onended = null;
      this.audioEl.onerror = null;
      this.audioEl = null;
    }
    if (this.audioUrl) {
      URL.revokeObjectURL(this.audioUrl);
      this.audioUrl = null;
    }
  }

  private cleanupSpeech(): void {
    if (this.utterance) {
      this.utterance.onboundary = null;
      this.utterance.onend = null;
      this.utterance.onerror = null;
      this.utterance = null;
    }
  }

  private cleanup(): void {
    this.cleanupAudio();
    this.cleanupSpeech();
    window.speechSynthesis.cancel();
  }
}

export const ttsManager = new TtsManagerSingleton();
```

## Step 4 — Typing Animation Hook (`src/features/canvas/useTypingAnimation.ts`)

**New file**. A React hook that subscribes to the `TtsManager` singleton's progress callbacks and returns the current character reveal count for a given node.

```typescript
import { useState, useEffect, useRef } from 'react';
import { ttsManager } from '@/lib/llm/ttsManager';
import { useNotebookStore } from '@/shared/stores/notebookStore';

/**
 * useTypingAnimation
 *
 * Returns the number of characters to reveal for the given node's text.
 * In notebook mode, starts at 0 and increments as TTS progresses.
 * In default mode (or if TTS never plays for this node), reveals fully.
 */
export function useTypingAnimation(nodeId: string, fullText: string) {
  const notebookMode = useNotebookStore((s) => s.notebookMode);
  const ttsPlaying = useNotebookStore((s) => s.ttsPlaying);
  const [revealed, setRevealed] = useState(fullText.length);
  const hasHadTts = useRef(false);

  useEffect(() => {
    if (!notebookMode) {
      // In default mode, never animate
      setRevealed(fullText.length);
      return;
    }

    // Reset to 0 when we enter notebook mode (text starts hidden)
    setRevealed(0);

    const onStart = (nid: string) => {
      if (nid === nodeId) {
        hasHadTts.current = true;
        setRevealed(0);
      }
    };

    const onProgress = (nid: string, charIndex: number) => {
      if (nid === nodeId) {
        setRevealed(Math.min(charIndex, fullText.length));
      }
    };

    const onEnd = (nid: string) => {
      if (nid === nodeId) {
        setRevealed(fullText.length);
      }
    };

    ttsManager.setCallbacks({
      onSegmentStart: onStart,
      onCharProgress: onProgress,
      onSegmentEnd: onEnd,
    });

    return () => {
      // If TTS never played for this node (e.g. unmounted before its turn),
      // reveal all text so it doesn't stay hidden
      if (!hasHadTts.current) {
        setRevealed(fullText.length);
      }
    };
  }, [nodeId, fullText, notebookMode]);

  // Keep revealed = full when not in notebook mode (even if ttsPlaying changes)
  useEffect(() => {
    if (!notebookMode) {
      setRevealed(fullText.length);
    }
  }, [notebookMode, fullText]);

  return { revealed, isAnimating: revealed < fullText.length };
}
```

### `SummaryNode.tsx` — Changes

Similar treatment but the recap is an array of strings. We need to:

1. Flatten the recap into a single string (join with `. `) for TTS
2. Animate each recap bullet appearing, then the next one

**Approach**: Track `revealedBullets` (how many bullets are fully revealed) and `revealedCharsInCurrent` (how many chars of the current bullet). The display shows:
- `data.recap.slice(0, revealedBullets)` fully rendered
- `data.recap[revealedBullets].slice(0, revealedCharsInCurrent)` partially revealed
- The rest hidden

This is slightly more complex than ConceptNode. If complexity is too high, start with a simpler approach: reveal one bullet at a time (no per-character within bullet).

**Simpler approach for v1**: Reveal bullets one-by-one with a `setInterval` after each concept's TTS segment ends. Each bullet appears fully formed, no character-level animation within bullets. This matches the "someone writing" feel for bullet lists.

- Strip card styling (CSS handles this)

```typescript
  if (!ttsManager.isPlaying && !ttsManager.isPaused) {
    ttsManager.start();
  }
}
```

### Implementation in `CanvasPage.tsx`

```typescript
import { useNotebookStore } from '@/shared/stores/notebookStore';
import { ttsManager } from '@/lib/llm/ttsManager';
import { Book, BookOpen, Play, Pause, SkipForward } from 'lucide-react';

function CanvasPage({ progress }: CanvasPageProps) {
  const notebookMode = useNotebookStore(s => s.notebookMode);
  const ttsPlaying = useNotebookStore(s => s.ttsPlaying);
  const ttsPaused = useNotebookStore(s => s.ttsPaused);
  const segmentIndex = useNotebookStore(s => s.segmentIndex);
  const totalSegments = useNotebookStore(s => s.totalSegments);
  const currentSegmentNodeId = useNotebookStore(s => s.currentSegmentNodeId);
  const setNotebookMode = useNotebookStore(s => s.setNotebookMode);
  const setTtsPlaying = useNotebookStore(s => s.setTtsPlaying);
  const setTtsPaused = useNotebookStore(s => s.setTtsPaused);

  const handleToggleNotebook = () => {
    const next = !notebookMode;
    setNotebookMode(next);
    document.body.toggleAttribute('data-notebook', next);

    if (!next) {
      // Turning off notebook mode — stop TTS, reveal all text
      ttsManager.stop();
    } else if (session) {
      // Turning on notebook mode — re-enqueue all concepts for TTS
      const conceptNodes = session.nodes.filter(n => n.data.kind === 'concept');
      const segments = conceptNodes.map(n => ({
        nodeId: n.id,
        text: `${(n.data as ConceptData).title}. ${(n.data as ConceptData).explanation}`,
      }));
      const summaryNode = session.nodes.find(n => n.id === '__summary__');
      if (summaryNode) {
        const summaryData = summaryNode.data as SummaryData;
        segments.push({
          nodeId: '__summary__',
          text: summaryData.recap.join('. '),
        });
      }
      ttsManager.enqueueMultiple(segments);
      ttsManager.setCallbacks({
        onSegmentStart: (nid) => {
          setTtsPlaying(true);
          setTtsPaused(false);
          useNotebookStore.getState().setCurrentSegment(nid);
        },
        onSegmentEnd: () => {
          useNotebookStore.getState().setCurrentSegment(
            ttsManager.currentSegmentId,
            ttsManager.currentQueueIndex,
            ttsManager.queueLength,
          );
        },
        onQueueEnd: () => {
          setTtsPlaying(false);
          setTtsPaused(false);
        },
      });
      ttsManager.start();
    }
  };

  // ... rest of component ...

  return (
    <div className={styles.container}>
      <ReactFlow ... />

      {/* Notebook toggle button */}
      <button
        className={styles.notebookToggle}
        onClick={handleToggleNotebook}
        title={notebookMode ? 'Exit Notebook view' : 'Notebook view'}
      >
        {notebookMode ? <BookOpen size={16} /> : <Book size={16} />}
        <span>Notebook</span>
      </button>

      {/* TTS controls (only visible in notebook mode while TTS is active) */}
      {notebookMode && (ttsPlaying || ttsPaused) && (
        <div className="notebookControls">
          <button onClick={() => {
            if (ttsPlaying) { ttsManager.pause(); setTtsPaused(true); setTtsPlaying(false); }
            else if (ttsPaused) { ttsManager.resume(); setTtsPlaying(true); setTtsPaused(false); }
          }}>
            {ttsPlaying ? <Pause size={14} /> : <Play size={14} />}
          </button>
          <button onClick={() => { ttsManager.skip(); }}>
            <SkipForward size={14} />
          </button>
          <span className="progressLabel">
            Concept {segmentIndex + 1}/{totalSegments}
          </span>
        </div>
      )}

      {/* Existing "Add note" button */}
      ...
    </div>
  );
}
```

## Edge Cases

| Case | Handling |
|------|----------|
| **Page reload mid-TTS** | Typing animation is ephemeral; nodes appear fully revealed on reload. User can toggle Notebook back on to restart TTS from the beginning. |
| **User toggles Notebook OFF mid-playback** | `ttsManager.stop()` clears queue and stops audio. All nodes revert to full-text. CSS restores card styling. |
| **User toggles Notebook ON after session is generated** | `handleToggleNotebook` re-enqueues all concept nodes + summary for TTS and starts playing from the beginning. |
| **User drags a node** | Notebook mode disables node dragging (`nodesDraggable={false}`) — text positions are fixed. |
| **Autoplay blocked by browser** | The audio `play()` call may throw. `TtsManager` catches this and falls back to `SpeechSynthesis` (which works without user gesture in most browsers after the first interaction). As a last resort, the controls bar has a Play button. |
| **LLM rate limit delay between concepts** | The existing 2-second `sleep()` provides natural pacing. TTS for concept N plays during the sleep + LLM call for concept N+1. |
| **Multiple concepts visible simultaneously** | Only the currently-playing node has the typing cursor. Previously played nodes show fully-revealed text. Future nodes show nothing (hidden) until their turn. |
| **Summary node with many recap bullets** | Bullets reveal one by one (full bullet appears at a time). After all bullets, the final quiz prompt appears. |
| **NVIDIA provider (no Mistral TTS)** | `ttsManager` falls back to `SpeechSynthesisUtterance` for all segments. Character progress is estimated from `onboundary` events. |
| **Empty queue edge case** | `start()` checks `queue.length === 0` and is a no-op. `skip()` on empty queue does nothing. |

## Success Criteria

1. **Toggle on**: Canvas shows ruled-line background, all nodes lose card styling (transparent, no borders/shadows/radius), quizzable content shows as italic with left accent bar.
2. **Auto-play**: After the first concept node appears, TTS begins playing the title + explanation. Text reveals character-by-character in sync with the voice.
3. **Controls**: A thin floating bar shows Play/Pause, Skip, and "Concept X/Y" progress indicator.
4. **Progress display**: TTS plays through all concepts sequentially, then the summary.
5. **Toggle off**: Canvas instantly reverts to the normal card-based view. All text is fully revealed. TTS stops.
6. **Mobile**: Same behavior in the mobile focus view — auto-TTS on the visible concept card.
7. **No regressions**: Default mode (Notebook off) behaves exactly as before. Existing Listen button on ConceptNode still works.
